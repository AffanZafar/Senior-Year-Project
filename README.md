# Black-Scholes

# Overview

This project implements the Black-Scholes model for option pricing along with numerical solutions using finite difference methods. It also includes volatility smile analysis and practical trading strategies implementation. The work compares analytical and numerical solutions and addresses the limitations of the Black-Scholes model by exploring the Heston model as an alternative.
Features

🧮 Black-Scholes analytical solution implementation. <br/>
📊 Numerical solution using the Implicit Finite Difference Method. <br/>
📈 Implied volatility calculation and volatility smile visualization. <br/>
💹 Implementation of options trading strategies (straddle and custom). <br/>
🔄 Comparison between Black-Scholes and Heston models. <br/>
🧪 Extensive benchmarking of numerical solutions.
